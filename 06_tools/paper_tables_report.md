## B. 仿射不变性检验：论文的指数描述统计能是管线指数的线性重表达吗？

- 论文 Table 1/4 报 Min = **0**、Max = **20**。
- 管线**完整样本**（17,686）的支撑区间 = [0, 20]，**与论文完全一致**；
  而管线**回归样本**（17,670）的 Min = **1**（剔除了杂交度为 0 的 16 款）。
- ⇒ 论文描述统计表报的 Min = 0 **只能来自 17,686 全样本**，但同一张表标注 N = 17,670：**这是「描述统计表口径混用」的第一处直接证据。**
- 在 0–20 的支撑上，若论文指数 = `a + b · 管线指数`（b > 0），端点必须同时满足 `a = 0` 与 `a + 20b = 20` ⇒ **a = 0、b = 1**，即**只能是恒等映射**。
- 于是论文的均值必须等于 **9.3145**（全样本）、中位数 **10.0**、SD **3.6682**。
- 实测：论文均值 10.35（差 **+1.0355**）、SD 4.14（差 **+0.4718**）——**均不成立**。

退一步，只看「平移」这一最弱的假设（论文 = 管线 + c）：

| 由哪个统计量定 c | 推出的 c | 与其他统计量是否相容 |
|---|---|---|
| Min（0 对 0） | 0 | — |
| Max（20 对 20） | 0 | — |
| Table 1 Median（10.0 对 10.0） | 0 | — |
| 拐点 Peak（11.96 对 11.96） | 0 | — |
| **Mean（10.35 对 9.3145）** | **+1.0355** | ❌ 与上面四个全部冲突 |
| SD（4.14 对 3.6682） | — | ❌ 平移不改变 SD，故 SD 也冲突 |

⇒ **六个量里有四个（Min / Max / Median / Peak）指向 c = 0，只有 Mean 指向 c = +1.03**；SD 在任何线性变换下都不可能与均值/中位数同时成立。

再检验「仿射」假设（用论文自己的三个统计量两两反解，验证第三个；管线基准取全样本）：

| 用哪两个反解 a, b | 解出 a | 解出 b | 预测的第三个 | 论文报的第三个 | 是否相容 |
|---|---|---|---|---|---|
| mean & median | +15.1061 | -0.5106 | 1.8730 | 4.1400 | ❌ 差 -2.2670 |
| mean & sd | -0.1625 | +1.1286 | 11.1236 | 10.0000 | ❌ 差 +1.1236 |
| median & sd | -1.2862 | +1.1286 | 9.2264 | 10.3500 | ❌ 差 -1.1236 |

`[实]` **三个两两反解全部失败** ⇒ 论文 Table 1/4 的 (mean, median, SD) 三元组**不是管线指数分布的仿射像**，因而不可能只是「换了个口径的同一个变量」。

### B2. 更强的封闭性论证：**任何子样本都不可能**得到均值 10.35

- 完整样本 17,686 款游戏的杂交度**总和** = **164,737.0**（均值 9.3145）；回归样本 17,670 款的总和 = **164,737.0**。
- 对任意子样本 S，恒有 `mean_S = sum_S / |S| ≤ sum_all / |S|`。

| 若描述统计的样本量为 | mean 的理论上界 | 论文报的 10.35 是否可能 |
|---|---|---|
| 17,670 | 9.3230 | ❌ 不可能 |
| 17,686 | 9.3145 | ❌ 不可能 |
| 17,633 | 9.3425 | ❌ 不可能 |
| 17,000 | 9.6904 | ❌ 不可能 |
| 15,933 | 10.3394 | ❌ 不可能 |
| 15,000 | 10.9825 | ✅ 可能 |

- 要让均值达到 10.35，保留的样本量必须 **≤ 15,917**，即需要**删掉至少 1,769** 款（且被删的全部是低杂交度样本）。
- 而 §G 反解出的描述统计样本量约为 **17,633**（仅比全样本少约 53 款），其均值上界为 **9.3425**。

`[实]` ⇒ **论文的 10.35 不可能由管线这套杂交度值的任何子样本产生**——既不能靠换仿射口径（§B），也不能靠删样本（本节）。它与下一条证据（VIF 显示回归用的正是管线这套指数）合起来，只剩两种解释：**①该描述统计是在一个维度数更多的另一版索引上算的；②该列本身算错了。**

把**论文 Table 4 自己的数字**代入同一恒等式（年份效应沿用管线，因论文 Y_2016 = 管线 −0.0449 逐位相同）：

- 代入 ȳ = 6.40、mean(Hc²) = SD² = 4.14² = 17.1396、p̄ = 11.60、β₂ = −0.0145、β₃ = +0.0381：
  a_pred = 6.40 + 0.0145×17.1396 − 0.0381×11.60 − (-0.3382) = **6.5448**
- 论文 Table 5 实际报 const = **6.3754** ⇒ 差 **-0.1694**
- 对照：若改用**管线**的指数统量（Var = 13.3893）：a_pred = 6.3997 + 0.0145×13.3893 − 0.0381×11.6020 − (-0.3382) = **6.4901** ≈ 管线实测 6.4904 ✅

`[实]` ⇒ 论文的截距 **6.3754 与它自己 Table 4 报的指数 SD = 4.14 不相容**；把 SD 换成管线的 3.6756 则恒等式立刻成立。**截距是第三条独立证据。**
